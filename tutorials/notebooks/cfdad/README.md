# CFDAD: forest disturbance attribution from prepared features

This example accompanies the **China Forest Disturbance Attribution Dataset (CFDAD), 2017–2025**. The workflow starts from an annual feature database (Parquet) prepared from time-series outputs generated with [`pyxccd`](https://github.com/Remote-Sensing-of-Land-Resource-Lab/pyxccd) (Ye and Hu, 2026). Its three commands fit a tile-specific random forest, predict one tile-year, and assemble a geographic ASDDD GeoTIFF.

## Run the 2024 Yajiang wildfire example

From this directory, run the commands in a Python 3.10–3.13 environment. The example includes two annual Parquet files, nine training CSVs, aligned forest rasters, and a geographic output grid. All inputs are local after installation.

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install .

demo=examples/yajiang_2024
for tile in 47RPP 47RQP; do
  cfdad train --tile "$tile" --routes "$demo/routes.json" \
    --training-dir "$demo/training" --output "output/${tile}.model" --jobs 4

  cfdad predict --tile "$tile" --year 2024 --model "output/${tile}.model" \
    --database "$demo/${tile}_2024_forest_normal.parquet" \
    --forest "$demo/${tile}_forest_clcd_2016.tif" \
    --output "output/${tile}_2024_ADDDS.tif" --jobs 4
done

cfdad mosaic --year 2024 --tiles "$demo/mosaic.json" \
  --grid "$demo/grid_wgs84.tif" --output output/Yajiang_2024_ASDDD.tif

python "$demo/select_wildfire.py" output/Yajiang_2024_ASDDD.tif \
  output/Yajiang_2024_wildfire_Mar15_Apr30_ASDDD.tif
```

`Yajiang_2024_ASDDD.tif` contains all disturbances mapped in the example region for 2024. The wildfire layer keeps the original five-digit codes for wildfire pixels with detection dates from 15 March through 30 April 2024. It uses `0` for monitored forest without a selected wildfire and `65535` for NoData.

The CSVs retain every training row from the nine source tiles used in build 1110_v2, with the columns required to train the models. Each Parquet includes the 2024 candidates within a buffered window of its source tile. The files retain full-grid row and column indices and the forest rasters retain their original extent, so mosaic overlap uses the original tile centers. See `examples/yajiang_2024/sample.json` for the windows and row counts.

## Run with a prepared feature database

| Input | Contract |
| --- | --- |
| Training CSVs | `<source>_combined.csv` for each of the nine ordered sources in the JSON or YAML route. Include the 19 feature columns and `label`. Classes `1`, `2`, `3`, `4` denote non-disturbance anomaly, wildfire, logging, and stress. If a target has a local CSV outside its nine sources, the default also uses that file. `--no-local` disables this addition. `config/targets_1110_v2.yaml` preserves the original production routes. |
| Annual feature database | One Parquet per tile-year. Include the 19 feature columns plus `row`, `col`, `detection_date`, and `detection_doy`. `row` and `col` are zero-based indices on the native forest raster grid. `detection_date` is `YYYYMMDD` and `detection_doy` is the corresponding day of year. |
| Forest raster | A single-band 2016 CLCD raster aligned to the database's native HLS grid. Forest is CLCD class `2`. For sites with updated terrain inputs, supply aligned `--dem` and `--slope` rasters to override the database columns. |
| Mosaic manifest | An ordered JSON list with keys `tile`, `disturbance`, and `forest`. Paths may be absolute or relative to the manifest. Supply full native tile rasters when mosaicking multiple overlapping tiles, because the distance comparison uses their raster centers. |
| Reference grid | A north-up EPSG:4326 raster that defines the output extent, origin, and spacing. Only its grid metadata is used. For the full national grid use a scratch volume with at least 100 GB free for intermediate rasters and connected-component labels. |

See [Feature and database fields](FEATURES.md) for the 19 predictors, their stored units and scaling, and their legacy aliases. Both the public and original column names are accepted for CSVs and Parquet files. `src/cfdad/schema.py` defines the model feature order. Train and predict with the same environment. Load only model files generated by a trusted training run.

## Map values

Tile prediction uses the 1110_v2 RF settings (150 trees, maximum depth 15, seed 42), assigns a majority disturbance class within each eight-connected patch of at least four pixels, and retains the detection day and spectral severity of each pixel. Severity grades 1, 2 and 3 correspond to stored `normalized_change_magnitude_6obs_x100` ranges 0–1508, 1509–2051, and 2052–32767.

The mosaic uses nearest-neighbor reprojection. Where several tiles detect a disturbance at the same output pixel, the complete tuple comes from the closest tile center. Equal distances follow the manifest order. A second eight-connected patch vote on the mosaic updates the class field alone. Class ties use the smallest class code.

The final single-band `UInt16` raster uses `0` for forest with no mapped disturbance, `65535` for NoData outside the forest mask, and `ASDDD` for disturbance (`10000 × A + 1000 × S + D`). Here `A` is `1` for wildfire, `2` for logging, and `3` for stress, `S` is severity, and `D` is day of year. The native tile intermediate uses `ADDDS` (`10000 × A + 10 × D + S`), with `0` as its empty value.

## Verification

On Linux, training from the bundled CSVs and predicting from the bundled Parquet files reproduced all 3,647,396 pixels in the regional maps from the full 2024 databases and the frozen 1110_v2 models. A fresh macOS run also completed. Its wildfire layer differed from the Linux result at 815 pixels.
